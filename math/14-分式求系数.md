# 生成函数与 Bostan–Mori

## 线性递推的普通生成函数

若序列满足

$$
a_n=c_1a_{n-1}+c_2a_{n-2}+\cdots+c_da_{n-d},
$$

则普通生成函数 $A(x)=\sum_{n\ge0}a_nx^n$ 可以写成

$$
A(x)=\frac{P(x)}{Q(x)},\qquad
Q(x)=1-c_1x-c_2x^2-\cdots-c_dx^d.
$$

当 $\deg P<d$ 时，

$$
P_i=a_i-\sum_{j=1}^{i}c_ja_{i-j}\quad(0\le i<d).
$$

因此求递推第 $n$ 项等价于求 $[x^n]P(x)/Q(x)$。Bostan–Mori 每轮把下标减半：

$$
\frac{P(x)}{Q(x)}
=\frac{P(x)Q(-x)}{Q(x)Q(-x)}.
$$

分母只含偶数次项；根据 $n$ 的奇偶，只保留分子的偶数项或奇数项。

下面代码依赖 `16-polynomial.md` 中的 `polynomial::multiply`、`mod_inverse` 和 `mod`。

```cpp
namespace polynomial {

vector<int> parity_coefficients(const vector<int>& poly, int parity) {
    vector<int> result;
    for (int i = parity; i < (int)poly.size(); i += 2) {
        result.push_back(poly[i]);
    }
    return result;
}

int bostan_mori(vector<int> numerator, vector<int> denominator,
                long long index) {
    assert(index >= 0);
    assert(!denominator.empty() && denominator[0] != 0);
    while (index > 0) {
        vector<int> denominator_negative = denominator;
        for (int i = 1; i < (int)denominator_negative.size(); i += 2) {
            if (denominator_negative[i] != 0) {
                denominator_negative[i] =
                    mod - denominator_negative[i];
            }
        }
        numerator = parity_coefficients(
            multiply(numerator, denominator_negative), index & 1);
        denominator = parity_coefficients(
            multiply(denominator, denominator_negative), 0);
        index >>= 1;
    }
    int constant = numerator.empty() ? 0 : numerator[0];
    return (int)((long long)constant * mod_inverse(denominator[0]) % mod);
}

} // namespace polynomial
```

复杂度为 $O(M(d)\log n)$，其中 $M(d)$ 是 $d$ 次多项式乘法复杂度。输入应满足 $\deg P<\deg Q$；从递推构造时自然满足这一条件。

常见 OGF/EGF 及建模规则统一见 `21-generating-functions.md`，公式速查见 `24-counting-formulas.md`。

## 常见陷阱

1. $Q(0)$ 必须可逆；通常先把分子分母同时除以 $Q(0)$，令分母常数项为 1。
2. 模数下的负系数要正规化到 $[0,p)$。
3. 从递推构造 $P$ 时只保留前 $d$ 项，不是直接把初值数组当作分子。
4. Bostan–Mori 的奇偶取自当前 `index`，取完系数后才右移。
