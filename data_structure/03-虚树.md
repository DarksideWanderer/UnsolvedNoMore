# 虚树

给定树上的关键点，只保留关键点及连接它们所需的 LCA。下面函数返回虚树根、节点列表和有向父子边；依赖预处理好的 DFS 序 `dfn`、`lca` 与祖先判断 `is_ancestor`。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct VirtualTree {
    int root = -1;
    vector<int> nodes;
    vector<pair<int, int>> edges;
};

template<class Lca, class IsAncestor>
VirtualTree build_virtual_tree(vector<int> key_nodes,
                               const vector<int>& dfn,
                               Lca lca, IsAncestor is_ancestor) {
    VirtualTree result;
    if (key_nodes.empty()) return result;
    sort(key_nodes.begin(), key_nodes.end(),
         [&](int lhs, int rhs) { return dfn[lhs] < dfn[rhs]; });
    key_nodes.erase(unique(key_nodes.begin(), key_nodes.end()), key_nodes.end());

    int original_size = (int)key_nodes.size();
    for (int i = 1; i < original_size; ++i) {
        key_nodes.push_back(lca(key_nodes[i - 1], key_nodes[i]));
    }
    sort(key_nodes.begin(), key_nodes.end(),
         [&](int lhs, int rhs) { return dfn[lhs] < dfn[rhs]; });
    key_nodes.erase(unique(key_nodes.begin(), key_nodes.end()), key_nodes.end());

    vector<int> stack;
    for (int node : key_nodes) {
        while (!stack.empty() && !is_ancestor(stack.back(), node)) {
            stack.pop_back();
        }
        if (!stack.empty()) result.edges.push_back({stack.back(), node});
        stack.push_back(node);
    }
    result.root = key_nodes[0];
    result.nodes = move(key_nodes);
    return result;
}
```

虚树点数不超过两倍关键点数减一，构造复杂度为 $O(k\log k)$。多次询问时只清空 `result.nodes` 中出现过的邻接表位置，不要每次清空整棵原树。
