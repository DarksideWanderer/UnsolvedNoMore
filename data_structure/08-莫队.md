# 莫队算法

莫队只负责安排询问顺序。答案结构由调用者维护：移动左、右端点时执行 `add(index)` 或 `remove(index)`，然后用 `get_answer()` 读取当前区间答案。

## 静态区间莫队

区间均为 0-based 闭区间。奇偶块反向排序右端点可以减少指针抖动。

```cpp
#include <bits/stdc++.h>
#include <cassert>
using namespace std;

struct MoQuery {
    int left;
    int right;
    int id;
};

template<class Answer, class Add, class Remove, class GetAnswer>
vector<Answer> mo_algorithm(int array_size, vector<MoQuery> queries,
                            Add add, Remove remove,
                            GetAnswer get_answer) {
    int block_size = max(1, (int)sqrt(max(1, array_size)));
    sort(queries.begin(), queries.end(), [&](const MoQuery& lhs,
                                             const MoQuery& rhs) {
        int lhs_block = lhs.left / block_size;
        int rhs_block = rhs.left / block_size;
        if (lhs_block != rhs_block) return lhs_block < rhs_block;
        return lhs_block & 1
            ? lhs.right > rhs.right : lhs.right < rhs.right;
    });

    vector<Answer> answers(queries.size());
    int current_left = 0;
    int current_right = -1;
    for (const MoQuery& query : queries) {
        assert(0 <= query.left && query.left <= query.right);
        assert(query.right < array_size);
        while (current_left > query.left) add(--current_left);
        while (current_right < query.right) add(++current_right);
        while (current_left < query.left) remove(current_left++);
        while (current_right > query.right) remove(current_right--);
        answers[query.id] = get_answer();
    }
    return answers;
}
```

若单次增删为 $O(1)$，常见复杂度为 $O((n+q)\sqrt n)$。查询编号必须恰好覆盖 $0,1,\ldots,q-1$。

## 带修改莫队

询问额外记录它之前发生的修改次数。修改对象应同时保存旧值和新值，使前进与回滚都为 $O(1)$。

```cpp
struct TimedMoQuery {
    int left;
    int right;
    int time;
    int id;
};

template<class Answer, class Add, class Remove,
         class Apply, class Rollback, class GetAnswer>
vector<Answer> mo_with_updates(
    int array_size, int update_count, vector<TimedMoQuery> queries,
    Add add, Remove remove, Apply apply, Rollback rollback,
    GetAnswer get_answer) {
    int block_size = max(1, (int)pow(max(1, array_size), 2.0 / 3.0));
    sort(queries.begin(), queries.end(), [&](const TimedMoQuery& lhs,
                                             const TimedMoQuery& rhs) {
        int lhs_left_block = lhs.left / block_size;
        int rhs_left_block = rhs.left / block_size;
        if (lhs_left_block != rhs_left_block) {
            return lhs_left_block < rhs_left_block;
        }
        int lhs_right_block = lhs.right / block_size;
        int rhs_right_block = rhs.right / block_size;
        if (lhs_right_block != rhs_right_block) {
            return lhs_right_block < rhs_right_block;
        }
        return lhs.time < rhs.time;
    });

    vector<Answer> answers(queries.size());
    int current_left = 0;
    int current_right = -1;
    int current_time = 0;
    for (const TimedMoQuery& query : queries) {
        assert(0 <= query.time && query.time <= update_count);
        while (current_left > query.left) add(--current_left);
        while (current_right < query.right) add(++current_right);
        while (current_left < query.left) remove(current_left++);
        while (current_right > query.right) remove(current_right--);
        while (current_time < query.time) {
            apply(current_time++, current_left, current_right);
        }
        while (current_time > query.time) {
            rollback(--current_time, current_left, current_right);
        }
        answers[query.id] = get_answer();
    }
    return answers;
}
```

`apply(update_id, left, right)` 应在修改位置位于当前区间时先删除旧值、写入新值、再加入新值；`rollback` 反向执行。常见复杂度为 $O(n^{2/3}(n+q))$ 次状态改变。

## 树上莫队

把 DFS 欧拉序列记录为“进入一次、离开一次”。移动指针时翻转对应点是否在集合中：

- 若 $\operatorname{lca}(u,v)=u$，使用区间 $[in_u,in_v]$；
- 否则使用 $[out_u,in_v]$，并在读取答案前临时加入 LCA；
- 必须先保证 $in_u\le in_v$。

路径区间公式取决于欧拉序列的具体定义，复制模板前应用链、祖先关系和跨子树三类样例手动检查。
